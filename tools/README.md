# Инструменты

Утилиты для разработчиков. Они готовят данные для сайта, но сами в него не входят: сайт (`frontend/`)
и бэкенд (`backend/`) их не импортируют и не запускают, на GitHub Pages они не попадают.

| Папка | Что делает |
|---|---|
| [`city-data/`](city-data/README.md) | собирает и проверяет данные городов из OpenStreetMap: вода, районы, схема дорог, плитки карты |

У каждого инструмента свои зависимости (`requirements.txt` в его папке). Запуск — из корня репозитория.
