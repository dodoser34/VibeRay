# 11. Словарь

| Термин | Что значит |
|---|---|
| агрегат | итог по району: среднее настроение, доли настроений, число отметок; отдельные отметки наружу не отдаются |
| бумажная карта | анимация перехода между страницами: карта разворачивается, под ней меняется страница, потом карта улетает к вкладке |
| ворота входа | момент, когда новая страница начинает свою вступительную анимацию (когда бумажная карта складывается) |
| замыкающий отрезок | короткая прямая между узлами OSM там, где границу района нужно провести, а линии в OSM нет (`closures`) |
| затравка | прежние районы Костаная; по ним скрипт решает, какому району отдать квартал |
| квартал | участок города, со всех сторон ограниченный линиями OSM: улицами, железной дорогой, берегом, контурами участков |
| кластер | несколько близких меток проблем, собранных в один значок с числом |
| модератор | роль, которая ведёт проблемы по статусам и отвечает на обращения; у неё свой интерфейс |
| OSM, OpenStreetMap | открытая карта мира, из неё берутся районы, улицы и вода (лицензия ODbL) |
| Overpass | API для запросов к данным OpenStreetMap |
| палитра района | число от 1 до 12, по нему выбирается цвет `--district-N`; у соседей числа разные |
| плита | район на 3D-карте: выдавленный полупрозрачный многоугольник |
| плитка | картинка 512 × 512 px с дорогами и водой; из плиток складывается подложка карты |
| порог приватности | если отметок меньше пяти, настроение района не показывается |
| слой | режим карты: «Районы», «Настроение» или «Проблемы» |
| slug | короткий латинский код вроде `kostanay`, `center`, `kzhbi`; используется в адресах и данных |
| токен (в дизайне) | CSS-переменная с цветом, отступом или шрифтом, например `--color-bg` или `--space-4` |
| токен (при входе) | access (15 минут, в памяти вкладки) и refresh (30 дней, в cookie); подтверждают, что пользователь вошёл |
| хорда залива | прямая между двумя вершинами района, которая закрывает залив соседнего района (`bays`) |
| чистка контуров | автоматическое удаление полосок, пирсов и щелей у районов после сборки (`district_edits.geojson`) |
| шторка | панель, выезжающая снизу экрана на телефоне; бывает свёрнута, открыта наполовину или почти целиком |
| EXIF | служебные данные фото, в том числе координаты и модель телефона; на сайте всегда удаляются |
