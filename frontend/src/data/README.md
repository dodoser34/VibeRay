# Демо-данные фронтенда

Всё, что нужно сайту, чтобы работать **без бэкенда** (локально и на GitHub Pages), лежит здесь и только здесь.
В компонентах, страницах и `shared/` демо-данных нет.

| Путь               | Что это                                                                               |
| ------------------ | ------------------------------------------------------------------------------------- |
| `cities/kostanay/` | снимок геоданных Костаная из OpenStreetMap: `city.json`, районы, улицы, вода (ODbL)   |
| `accounts.json`    | демо-пользователи: вход `demo@viberay.kz` / `demo12345`                               |
| `content.json`     | демо-содержимое: описания тестовых проблем, ники жителей, названия сервисов в статусе |
| `api/handler.js`   | фейковый API: те же пути `/api/v1`, коды ошибок и валидация, что у будущего FastAPI   |
| `api/generate.js`  | генератор демо-статистики: история настроений с 2023 года, проблемы, дашборд города   |

## Как это подключено

`shared/api/client.js` отправляет запросы в `api/handler.js`, пока `VITE_USE_MOCKS` не равен `false`
(по умолчанию — демо-режим). Компоненты про это не знают: они вызывают `shared/api/endpoints/*`.
Единственное исключение — подсказка демо-входа в `features/auth/components/LoginForm.jsx`,
она видна только в демо-режиме.

## Когда появится бэкенд

1. В `frontend/.env` поставить `VITE_USE_MOCKS=false` — запросы пойдут на `/api/v1`.
2. Проверить, что ответы бэкенда совпадают с контрактом (ARCHITECTURE.md, раздел 7).
3. Если демо-режим больше не нужен, удалить эту папку, ветку `USE_MOCKS` в `client.js`
   и подсказку демо-входа в `LoginForm.jsx`.

Исходные геоданные для бэкенда лежат в `backend/data/cities/`. `cities/` здесь — их копия для демо:
при обновлении районов копируйте файлы в обе папки.
