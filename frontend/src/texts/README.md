# Тексты сайта

Весь текст, который видит пользователь, лежит здесь — в JSON-файлах по разделам сайта, на четырёх языках:

- `ru/` — русский, основной;
- `kk/` — казахский, `en/` — английский, `de/` — немецкий: **те же файлы и те же ключи**, другие значения.

Чтобы поменять надпись, найди её в нужном файле и исправь значение справа от двоеточия — во всех языках.
Сайт подхватывает изменения сразу (в режиме `npm run dev` — без перезагрузки; если после правки перевод
показывает русский текст, перезапусти `npm run dev`). Язык переключается флагами в шапке сайта (плавно, без
перезагрузки); у каждого языка свой адрес: русский — без префикса, остальные — `/kk/…`, `/en/…`, `/de/…`.

| Файл                 | Что в нём                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `nav.json`           | таб-бар и мобильное меню (пункты, аккаунт гостя), название сайта, названия страниц в переходе     |
| `home.json`          | главная: заголовок, подзаголовок, подсказка «листай»                                              |
| `auth.json`          | вход и регистрация: поля, шаги, подсказки, ошибки, варианты ников, надёжность пароля              |
| `map.json`           | страница карты: панели, слои, легенды, кнопка статистики, уведомления, окно «нужен аккаунт», OSM  |
| `mood.json`          | выбор настроения, легенда настроений                                                              |
| `problems.json`      | сообщение о проблеме (шаги, подсказки, ошибки), карточка проблемы                                 |
| `stats.json`         | панель района и дашборд города: настроение, плитки, график, таблицы районов и лет, шкалы карты    |
| `about.json`         | «О проекте»: главы истории, календарь, экран монитора, блок «Как это работает», полная история    |
| `support.json`       | поддержка: поиск, категории, **вопросы и ответы (FAQ)**, форма обращения, статус сервиса          |
| `settings.json`      | настройки профиля: разделы, аватар и никнейм, свой район, смена пароля, выход и удаление аккаунта |
| `notifications.json` | уведомления: колокольчик, панель, тексты событий («подтвердили», «взяли в работу», «решена»)      |
| `moderation.json`    | интерфейс модератора: сводка, очередь и действия, отклонение, город, обращения, карта модератора  |
| `notFound.json`      | страница 404 «Этот район ещё не нанесён на карту»                                                 |
| `dictionaries.json`  | названия настроений, периодов, категорий и статусов проблем, тем обращений, состояний сервиса     |
| `transition.json`    | подписи на бумажной карте перехода между страницами                                               |
| `common.json`        | общее: «Закрыть», «только что / N мин назад», ошибки фото, «сервер недоступен»                    |
| `errors.json`        | сообщения об ошибках от сервера (в демо-режиме — от фейкового API в `src/demo-data`)              |

## Правила

- **Меняй только значения** (текст справа). Ключи слева — это адреса текста в коде: если переименовать ключ,
  надпись пропадёт.
- **`{name}` в фигурных скобках** — место, куда сайт сам подставит значение (имя района, число, время).
  Скобки и слово внутри оставляй как есть, текст вокруг можно менять.
- **Массив из трёх слов** (например, `["отметка", "отметки", "отметок"]`) — формы для чисел 1 / 2 / 5.
  В английском и немецком — те же три места: `["mark", "marks", "marks"]` (для 1 берётся первое, иначе
  третье). В казахском после числа слово не меняется — одно слово во всех трёх местах: `["белгі", "белгі", "белгі"]`.
- **Новый ключ или файл — сразу во все четыре языка.** Новый файл раздела ещё подключается в `shared/lib/language.js`.
- Названия языков («Русский», «Қазақша», «English», «Deutsch» в `common.json`) пишутся на самих языках и одинаковы
  во всех файлах.
- Кавычки внутри текста — в русском и казахском «ёлочки», в английском “лапки”, в немецком „лапки“, или
  экранированные `\"`: обычная `"` сломает файл.
- Коды в `dictionaries.json` и `support.json` (`excellent`, `garbage`, `account`…) должны совпадать с кодами
  бэкенда — меняй только подписи.
- Названия районов здесь нет: они приходят из данных OpenStreetMap (`name`, `name_en`, где есть — `name_kk`, `name_de`; в демо-режиме —
  `src/demo-data/cities/kostanay`, с бэкендом — из API на языке запроса).
- Заголовок вкладки браузера — в `frontend/index.html` (он нужен до загрузки скриптов).
