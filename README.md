# VibeRay

VibeRay — 3D-карта города, на которой жители отмечают своё настроение и сообщают о проблемах в своём районе:
мусор, ямы, тёмные дворы, пробки. Соседи подтверждают сообщения, модератор ведёт их до решения, а по карте
видно, как живёт каждый район.

Первый город — Костанай, у него 14 районов, собранных по данным OpenStreetMap. Кроме него на карте есть Кёльн
(9 округов), Санкт-Петербург (18 районов), Бристоль (34 округа) и Астана (6 районов) в официальных границах
OpenStreetMap.

Сайт: https://dodoser34.github.io/VibeRay/

## Что есть на сайте

| Раздел | Что там |
|---|---|
| Карта | 3D-город из районов. Цвет и высота района показывают его настроение. Слои «Районы», «Настроение», «Проблемы». В тёмной теме город ночной, в светлой дневной |
| Настроение | отметка в одно касание, семь вариантов. Другим видно только среднее по району и только если отметок не меньше пяти |
| Проблемы | категория, точка на карте, описание, до трёх фото. Соседи подтверждают, модератор меняет статус: новая, подтверждена, в работе, решена. Спам и дубли отклоняются |
| Статистика | карточка района с настроением, графиком и проблемами; дашборд города за месяц, год или все годы; сравнение двух районов |
| Профиль | вход и регистрация, мои сообщения, уведомления, мой район. Другим видны только ник и аватар |
| Модератор | отдельный интерфейс: очередь проблем, карта, проблемные районы, обращения в поддержку |
| О проекте и поддержка | история идеи, ответы на частые вопросы, форма обращения |
| Экраны | на телефоне свой интерфейс со шторкой и меню; поддерживаются планшеты, ноутбуки, 2K и 4K |
| Языки и темы | английский (основной), русский, казахский, немецкий; тёмная и светлая тема. Переключаются без перезагрузки, у каждого языка свой адрес (английский — без префикса, `/ru/`, `/kk/`, `/de/`) |

## Как запустить

Нужен Node.js 24 LTS (npm ставится вместе с ним).

```bash
cd frontend
npm install
npm run dev
```

Сайт откроется на http://localhost:5173.

Другие команды (запускаются в папке `frontend/`):

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер, изменения подхватываются на лету |
| `npm run build` | собирает сайт в `frontend/dist` |
| `npm run preview` | показывает собранный сайт |
| `npm run lint` | проверяет код ESLint |
| `npm run format` | форматирует код Prettier |

### Скрипты геоданных

Районы, улицы и плитки карты собираются скриптами на Python 3.12+ из данных OpenStreetMap. Это инструменты,
а не часть сайта, поэтому они лежат отдельно — в `tools/city-data/`. Для них нужно поставить зависимости:

```bash
python -m venv .venv
.venv\Scripts\activate              # Windows; на macOS и Linux: source .venv/bin/activate
pip install -r tools/city-data/requirements.txt
```

Скрипты запускаются из корня репозитория по порядку, вместо `kostanay` можно указать `cologne`,
`saint-petersburg`, `bristol` или `astana`:

```bash
python tools/city-data/build_districts.py kostanay    # районы
python tools/city-data/build_streets.py kostanay --save-osm tools/city-data/.osm-cache/kostanay-streets.json
python tools/city-data/build_map_tiles.py kostanay    # плитки карты
python tools/city-data/verify_city_data.py kostanay   # проверка: итог «ПРИНЯТО»
```

Вторая команда собирает схему дорог и сохраняет ответ OpenStreetMap — по нему работает проверка, а повторная
сборка дорог идёт без сети (`--osm` вместо `--save-osm`). Остальные ответы OpenStreetMap скрипты сохраняют в
`tools/city-data/.osm-cache/` сами (в git эта папка не попадает). Какие районы у какого города и откуда они берутся
в OpenStreetMap, записано в `tools/city-data/cities.py`. Новый город начинается с воды:
`python tools/city-data/build_water.py <город>` (у готовых городов вода уже собрана, и пересобирать её
без нужды не стоит — после неё пересобирается всё остальное).

Как это работает, описано в [docs/guide/07-geodata-pipeline.md](docs/guide/07-geodata-pipeline.md).

### Бэкенд

Кода бэкенда пока нет, и база данных ещё не выбрана. В `backend/requirements.txt` и `requirements-dev.txt`
записаны библиотеки и версии, на которых он будет написан. Все запросы сайта к нему идут на `/api/v1`.

## Что используется

### Программы

| Программа | Для чего |
|---|---|
| Node.js 24 LTS и npm | запуск и сборка сайта |
| Git | история изменений |
| Python 3.12+ | скрипты геоданных, в будущем бэкенд |

### Сайт (`frontend/package.json`)

Всё ставится командой `npm install`, точные версии записаны в `package-lock.json`.

| Библиотека | Для чего |
|---|---|
| react, react-dom 19 | интерфейс: страницы, модули, общие элементы |
| react-router 8 | адреса страниц (`src/app/routing/router.jsx`) |
| three | 3D-карта (`src/features/map/scene`) и 3D-город в истории «О проекте» |
| gsap, @gsap/react | анимации: перелёты камеры, панели, переходы между страницами, история на прокрутке, смена языка |
| qrcode | QR-код «Открой на телефоне» на главной |
| vite 8, @vitejs/plugin-react | сборка и dev-сервер |
| eslint 9 и плагины, globals | проверка кода |
| prettier | форматирование кода |

Стили написаны на CSS Modules с CSS-переменными, без CSS-фреймворков. Цвета тем лежат в
`src/styles/themes/`, отступы, шрифты и остальное — в `src/styles/tokens.css`.

### Бэкенд (`backend/requirements.txt`, `backend/requirements-dev.txt`)

| Библиотека | Для чего |
|---|---|
| fastapi, uvicorn | REST API и сервер (в планах) |
| pydantic, pydantic-settings, email-validator | схемы запросов и ответов, настройки из `.env` |
| pyjwt, argon2-cffi | токены входа и хеши паролей |
| python-multipart, pillow | загрузка фото и удаление из них геометок |
| pytest, pytest-asyncio, httpx, ruff | тесты и проверка кода |

### Скрипты геоданных (`tools/city-data/requirements.txt`)

| Библиотека | Для чего |
|---|---|
| pillow | рисует плитки карты |
| shapely | геометрия: вода, районы, дороги, проверка |

### Данные

Районы, улицы и вода взяты из OpenStreetMap (лицензия ODbL), поэтому на карте всегда есть подпись
«© участники OpenStreetMap». Данные каждого города лежат в `backend/data/cities/<город>/`, а копия районов, воды и
описания города для сайта — во `frontend/src/demo-data/cities/<город>/`. Схема дорог хранится только в
бэкенде, по файлу на район. Сайт её не скачивает, а показывает готовые плитки из `frontend/public/maps/`.
